# 문 너머: 사라진 기록실

24개 사건을 탐험하는 한국어 방탈출 웹게임입니다. [게임 시작하기](https://rumins01.github.io/door-archive-play/)에서 바로 플레이할 수 있어요.

## 핵심 요약

- 추리, 모험, SF, 판타지, 스릴러 이야기를 담았습니다.
- 단서 240개를 모아 퍼즐 120개를 풀어요.
- 진행 상황과 메모는 현재 브라우저에 자동 저장됩니다.
- 이 저장소는 GitHub Pages에 게시하는 게임 파일을 관리해요.

## 배포

GitHub Pages는 `main` 브랜치의 루트 폴더를 게시합니다. 변경 사항을 이 브랜치에 올리면 사이트가 갱신돼요.

## 근거와 이력

최초 배포 파일은 원본 프로젝트의 `dd67b3c9cc15b6384388fd4885808cbd5e52d955` 커밋에 있는 `dist` 폴더에서 가져왔습니다. 조사에 참고한 자료는 게임의 ‘제작과 참고 자료’에서 확인할 수 있어요.
