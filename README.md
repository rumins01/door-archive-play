# 문 너머

방을 둘러보고, 물건을 찾아 합치고, 그림 자물쇠를 풀어 탈출하는 모바일 방탈출 웹게임입니다. [게임 시작하기](https://rumins01.github.io/door-archive-play/)에서 바로 플레이할 수 있어요.

## 핵심 요약

- 새 방탈출 "사서의 방"을 장면, 가방, 자물쇠 조작으로 플레이합니다.
- 이전 판의 추리형 사건 24개는 [이전 버전 사건 기록](https://rumins01.github.io/door-archive-play/legacy.html)에서 그대로 플레이할 수 있어요.
- 진행 상황은 현재 브라우저에 자동 저장됩니다. 새 판(`beyond-the-door.v2`)과 이전 판(`beyond-the-door.v1`) 기록은 따로 저장돼요.
- 이 저장소는 GitHub Pages에 게시하는 게임 파일만 관리합니다. 원본 소스와 검사는 비공개 저장소에 있어요.

## 배포

GitHub Pages는 `main` 브랜치의 루트 폴더를 게시합니다. 원본 프로젝트의 `dist` 폴더 파일을 이 저장소 루트에 복사하고 `.nojekyll`을 유지해요.

## 근거와 이력

- 최초 배포 파일은 원본 프로젝트의 `dd67b3c9cc15b6384388fd4885808cbd5e52d955` 커밋에 있는 `dist` 폴더에서 가져왔습니다. 조사에 참고한 자료는 이전 판 게임의 '제작과 참고 자료'에서 확인할 수 있어요.
- 2026-10-04 새 방탈출 판을 `index.html`로 올리고, 이전 판을 `legacy.html`로 옮겼습니다.
